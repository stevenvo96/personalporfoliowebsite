#Personal Portfolio Website

Welcome to this project, where I deploy my personal portfolio website using AWS services!

*Services used:

- **Amazon S3**: I am using S3 to hold and deploy the files necessary for the website to run.
- **CloudFront**: I am using CloudFront for more security and lower latency 
- **Amazon Route53**: I am using Route53 to translate the IP address into a custom domain
- **ACM Certificate Manager** I am using ACM to easily apply SSL certificates for HTTPS connections on my custom domain.
